# pef-longtext — 长文本拜占庭污点审计

> **功能一句话**：百万字级长文本分片遍历审计，π-Mod3 相位调度 + 洋葱 L1-L4 递进 + C 层 10 项校验 + 12 类拜占庭污点确定性检出——**防 AI 幻觉、防数据污染、防"AI 屎山"**。

## 功能（对应 SKILL.md）

- **分片遍历**：长文本按 chunk 切分逐片审计（重型模式支持百万字）
- **π-Mod3 相位调度**：chunk 序号 mod 3 → P（探索）/ E（收敛）/ F（裁决）
- **三元组探针**：提取 {主体, 变量, 结果} 判定 π 域 / √2 域
- **洋葱 L1-L4**：实体拆解 → 不等式建立 → 拓扑匹配 → 毁灭性证伪
- **C 层 10 项校验**：E 层独立执行
- **12 类拜占庭污点**：无锚论断 / 实体分类 OTHER / 数值冲突 / 时间逆序 / 熵不足 / 悬而未决 / 未注册变量 / π 伪造 / 重复指纹 / 洋葱跳层 / 灰色地带 / 无证伪
