## 共同的设计哲学

两个案例虽然领域不同，但共享同一套 PEF 第一性原理的设计决策：

### 1. 软件只提供建议，硬件做最终裁决

- **踝关节外骨骼**：P域MCU计算力矩建议，F域三输入与门（纯硬件）做最终使能裁决。安全回路响应时间纳秒级，不依赖任何软件中断。
- **物理AI审计**：被审计AI只提交状态提案，裁决权在独立的三权分立体系（规格权/统计权/调度权），AI无法通过自我报告绕过审计。

### 2. 变量分流：可控 vs 不可控

- **踝关节外骨骼**：P域可控输入（目标角度、控制参数）与E域不可控环境量（独立传感器读数、物理关节角度）严格分流，E域比较器拥有独立的模拟传感器输入。
- **物理AI审计**：被审计系统输出（S_t）与独立工程规格（R_spec）、公开π数位表严格分离，裁决变量中不含任何AI自报量。

### 3. 物理确定性优先于逻辑完备性

- **踝关节外骨骼**：唯一公理——物理确定性优先于逻辑完备性。所有缺损态等于执行器关断，掉电、断线、时钟停振、MCU跑飞统一切断输出。
- **物理AI审计**：偏差定义锚定于李群SO(3)/SE(3)结构而非AI输出，值域由几何结构内生给定，AI无法通过自我报告绕过定义。

### 4. 诚实的边界声明

- **踝关节外骨骼**：V5.2诚实声明E域传感器供电/信号调理/物理安装尚未完成环境应力测试；M层独立供电依赖主逻辑电源轨储能电容，极端场景下有已知局限。
- **物理AI审计**：明确声明不适用于学习型三维重建管线、不覆盖语义漂移、合成层存在参数黑箱；体系检测并记录Owner背叛，不阻止Owner背叛。

## PEF 架构的跨领域一致性

这两个物理应用实例证明了 P/E/F 第一性原理的**跨领域适用性**：

```
LLM 幻觉治理          物理工程系统
    │                     │
    ├─ P层：工蜂识别      ├─ P层：MCU策略建议
    ├─ E层：算子执行      ├─ E层：比较器安全校验
    ├─ F层：偏差裁决      ├─ F层：与门最终裁决
    ├─ M层：元认知审查    ├─ M层：看门狗独立观测
    └─ C层：闭环验证      └─ C层：示波器实测验证
    │                     │
    └── 共享同一套 P/E/F 第一性原理 ──┘
        拆解 → 分流 → 枚举 → 试错 → 逼近
```

**同一套地基，不同的上层建筑。** 这正是第一性原理的价值——它不是某个领域的专用框架，而是一套可跨领域复用的拆解重构工作流。
