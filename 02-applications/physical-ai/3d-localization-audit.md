## 一、问题域

以多模态世界模型为代表的物理AI系统将视觉输入绑定三维位姿并整合进统一坐标系。该类系统的三维参照轴实现方法未公开，且存在两个已知风险：

1. **数据转译为文本引入偏差与token消耗膨胀**
2. **二维到三维转换缺乏独立于模型自身的偏差校验手段**

### 审计问题的定位

本体系解决的是**审计问题**而非**表征问题**：
- **表征问题**（视觉与文本如何统一为三维场景）是模型内部事务
- **审计问题**（转换输出的偏差是否在规格内、记录是否未被篡改）是外部事务
- 两者正交。本体系仅在下游系统为安全关键场景时提供事后审计价值

### 设计哲学

**用最少的确定性约束锁定最大的不确定性**：
- 几何公理锁偏差定义
- 统计检验锁量测可信性
- 公开确定性序列锁审计密度下限
- 硬件隔离锁最终裁决
- 软件层负责搜索与生成，硬件层负责裁决与关断，权力分立

## 二、三个核心设计决策

### 决策一：偏差定义锚定于李群结构而非AI输出

三维旋转偏差在SO(3)上具有解析定义，其值域由几何结构内生给定，AI无法通过自我报告绕过该定义。

**旋转偏差公式**：
```
θ_err = arccos( (tr(R_refᵀ · R_act) − 1) / 2 )    θ_err ∈ [0, π]
```

**归一化旋转偏差率**：
```
ρ_rot = θ_err / π ∈ [0, 1]
```

> θ_err的右侧只依赖两个旋转矩阵本身：tr(R_refᵀ·R_act)是SO(3)群结构内生量，其取值使θ_err必然落在[0, π]。定义空间（值域、单调性、可计算性）由李群结构决定，与产生R_act的管线无关。

**对比反例**：若偏差由被审计AI自报（置信度、内部评分等），则定义空间由模型内部参数决定——审计对象与审计参照合一，构成自我认证，审计在结构上失效。因此"锚定结构而非AI输出"不是方案优选，而是审计成立的必要条件。

### 决策二：裁决权三权分立

| 权力 | 回答问题 | 判决类型 | 复现契约 |
|------|---------|---------|---------|
| **规格权** | 状态是否在工程规格区间内？ | 政策陈述（"应不应该"） | 自包含：π数位表、规格区间与记录内容即可复算 |
| **统计权** | 这条量测可信吗？ | 概率陈述（"信不信"） | 依赖估计器运行历史，第三方不可复算，仅记录供事后审计 |
| **调度权** | 哪些周期执行昂贵的重审计？ | 资源陈述（"何时查"） | 可查表复算 |

**三权各自独立判决、各自独立复现契约、显式优先级合并，互不冒充。**

> 三权各自回答的问题分属三种不同类型的陈述，三种陈述之间不存在推理通道：从政策常数λ推不出量测可信性（λ无统计根基），从卡方分位数推不出任何规格语义。三权分立因此是语义正交性的结构结论，不是组织偏好。

### 决策三：审计调度采用三通道纵深

**不可兼得三角**：单一机制在单一时刻最多同时占有{公开可复算、不可预测、统计校准}中的两角。三通道设计将三角分解到三个通道与两个时间相位上，每层各占两角，系统整体呈纵深防御。

| 通道 | 机制 | 三角占位 | 角色 |
|------|------|---------|------|
| **L0 公开保底层** | π数位公开排班（D_n mod 3确定性排班） | 公开可复算 + 密度政策 | 审计密度下限保证 |
| **L1 硬件随机层** | 硬件随机触发 | 不可预测 + 统计校准 | 补充不可预测性 |
| **L2 密钥延迟披露层** | 密钥延迟披露排班 | 执行时保密 + 事后可复算 | 兼具执行时保密与事后可复算 |

## 三、四层体系结构

```
┌─────────────────────────────────────────┐
│  审计层：锚定哈希链 + 三分复现契约 + PIMEM树  │
│  （记录全部判决，外部锚定，防重放盐值）      │
├─────────────────────────────────────────┤
│  调度层：三通道审计排班                     │
│  L0 π数位公开保底 / L1 硬件随机 / L2 密钥延迟披露 │
├─────────────────────────────────────────┤
│  裁决层：三权分立                          │
│  规格权（ρ-λ符合性） / 统计权（χ²门控） / 优先级合并 │
├─────────────────────────────────────────┤
│  几何层：李群结构偏差定义                   │
│  SO(3)/SE(3) 解析公式，π为投影之一          │
└─────────────────────────────────────────┘
```

**每层回答且仅回答一个问题，层间接口显式成文**——这是对抗评估确立的分界判据：缝合怪与分层架构的区别在于缝合线是否可见。

### 单向依赖

四层构成单向依赖：
- 几何层定义度量（被裁决层消费）
- 裁决层产生判决与标签（被审计层记录、被调度层的标签语义承载）
- 调度层决定时隙（其输出作为标签进入审计层）
- 审计层记录全部判决（消费上游全部输出，不反向修正任何上游定义）

> 单向性保证审计层是纯观察者：记录者不改变被记录的过程，这是记录可信的前提之一。

## 四、核心概念定义

### 主体（审计对象轴）

**形式定义**：主体 = 一个被审计的持久执行单元。在本应用域中，主体 = 一次任务部署中的一个物理AI定位系统。被审计的是定位输出，不是模型内部表征。

**结构对应（一对一强制）**：
```
一个主体 = 一个 Π_anchor = 一条审计链 = 一棵 PIMEM 树
```

多主体互不共链、互不共树——记录天然按链分离。

**锚分配规则**：主体按注册顺序 i 分配 π 小数位段 [i×256, (i+1)×256) 的 256 bit 数字锚。规则公开、单调递增、位段不重叠。

> 锚是标识符，不是密钥——公开确定性正是可验证性的来源，无保密性主张。

### S_t（被审计状态提案）

**形式定义**：S_t 为被审计对象在周期 t 提交的状态提案，属于配置空间 𝒮。

```
S_t = (T_t, v_t, b_t)
T_t ∈ SE(3)：六自由度位姿（旋转3 + 平移3）
v_t ∈ ℝ³：速度（可选）
b_t ∈ ℝ^k：传感器偏置（可选）
```

**裁决语义**：规格权审议的对象是"待锁定状态提案"——管线输出的状态更新提案。提案通过裁决（J=PASS）才锁定为事实状态；未通过者不进入事实空间。

### ΔV_t（状态增量）

**形式定义**：
```
ΔV_t = Log( T_{t−1}^−1 · T_t ) ∈ se(3)
```

六维李代数向量：旋转三分量（弧度）+ 平移三分量（米）。

> ΔV自带混合量纲（弧度+米），按量纲公理不得直接进入裁决域——须经ρ归一化参与判决；链上原始记录保留带量纲原值供事后复核。

### K_quantum（质变分叉刻度）

**形式定义**：
```
mod_metric = Σ_{i∈已锁定} ρ_i    （自上次质变分叉起累计）
触发条件：mod_metric ≥ K_quantum → 质变分叉，旧分支冻结为里程碑
```

K_quantum = k_q × r_spec，k_q 为 Owner 注册时设定的政策整数，写入 P_base 创世快照。

### 重审计（调度对象）

- **常规审计**（每周期）：算 ρ → 对照 λ_policy → 追加链记录。成本 O(1)
- **重审计**（时隙触发的五类操作）：对裁决机制本身的抽检，与对状态的常规裁决属于不同对象

> 重审计不是"更严的λ_policy"——λ_policy固定不轮换（三权分立的既定裁决），重审计是对裁决机制本身的抽检。三通道排班的是R1–R5的执行时隙。

## 五、几何层：李群结构与偏差定义

### 三个偏差率

| 偏差率 | 公式 | 覆盖 |
|--------|------|------|
| **ρ_rot** | θ_err / π | 旋转偏差 |
| **ρ_view** | δθ / (FOV/2) | 视角偏差（像素域→角度域换算） |
| **ρ_z** | \|ΔZ\| / Z_ref | 深度偏差 |

> 三个偏差率覆盖几何偏差子集：旋转、视角、深度。**语义漂移（几何正确但物体身份错误）明确不在覆盖范围**（硬边界声明）。

### ρ合成规则

```
ρ(S_t, R_spec) = √( w₁·ρ_rot² + w₂·ρ_view² + w₃·ρ_z² )
```

权重 w₁、w₂、w₃ 为工程拟合参数。

> **参数黑箱声明的精确边界**：白盒性止于分量定义，合成层显性承认参数性。

### π约定的论证

归一化分母取π或2π均合法，两者相差常数倍：ρ_rot=θ_err/π与θ_err/2π仅分辨率刻度不同，判决单调性不变，λ_policy在两种约定下同步缩放。本体系取π，与3.2公式中自然出现的π同源——这使"π绑定偏差，绑在公式里成立"字面成立：此处的π是SO(3)测地距离的最大值常数，不是小数位流的属性。

### 投影可换

不可替换的是李群SO(3)/SE(3)的结构本身；π是这一结构在具体公式中的投影之一。旋转偏差存在多种等价解析表示——arccos迹公式、四元数对数、Rodrigues反解——每种表示中π出现的位置不同。**结构不变，投影可换。**

## 六、裁决层：三权分立

### 规格权（符合性裁决，硬裁决层）

```
J = FAIL ⟺ ρ(S_t, R_spec) ≥ λ_policy
```

λ_policy为以规格区间为单位的政策倍数，固定，不随时间轮换。真值参照为工程规格区间（spec-as-region）。

> **设计裁定**：λ无统计根基不是缺陷——符合性检查的正确语义就是政策常数，规格即政策。

### 统计权（量测门控，外部模块）

**马氏距离检验**：
```
d² = νᵀS⁻¹ν，ν = z − Hx̂，S = HPHᵀ + R
```

判决基于卡方分布分位数。门控FAIL时量测进入预演隔离，本轮不作状态更新、不对被污染数据执行符合性裁决，记录标签STAT_FAIL。

> **复现契约（显性声明）**：该权判决依赖估计器运行历史，不可独立复算，仅记录供事后审计——这是该层的先天代价，写入契约而非隐藏。

### 调度权（审计时隙排班）

D_n mod 3折叠π数位序列为有限时隙序列，决定重审计排班。

> **语义变更显性标注**：折叠机制保留，折叠输出的语义从"审问强度档位"变更为"重审计时隙"——这是带告警的授权变更，非静默漂移。

### 优先级合并

- 符合性FAIL为硬失败，无论统计权判决如何
- 统计权FAIL使本轮周期作废（对不可信量测执行符合性判断无意义）
- 两类判决分标签独立入链

## 七、PEF 架构映射总结

| PEF 层 | 物理AI审计实现 | 核心机制 | 核心功能 |
|--------|---------------|---------|---------|
| **P层** | 被审计物理AI定位系统 | 主体定义 + π锚绑定 + 状态提案S_t | 提交状态提案，不参与裁决 |
| **E层** | 几何层 + 统计权 | 李群SO(3)/SE(3)偏差定义 + 马氏距离检验 | 独立于AI的偏差定义与量测可信性校验 |
| **F层** | 规格权 + 调度权 | ρ-λ符合性裁决 + 三通道审计排班 | 最终裁决：状态是否在规格内、何时执行重审计 |
| **M层** | 三权分立 + 优先级合并 | 规格权/统计权/调度权独立判决 | 元认知：权力分立、语义正交、互不冒充 |
| **C层** | 审计层 + PIMEM树 | 锚定哈希链 + 三分复现契约 + 质变分叉 | 闭环验证：记录全部判决、外部锚定、防篡改 |

## 八、诚实边界声明

1. **不适用于学习型三维重建管线**：本体系假设被审计系统提交的是确定性状态提案S_t，不适用于端到端学习型重建管线的内部表征
2. **不覆盖语义漂移**：三个偏差率覆盖几何偏差子集（旋转、视角、深度），语义漂移（几何正确但物体身份错误）明确不在覆盖范围
3. **合成层存在参数黑箱**：ρ合成规则的权重w₁、w₂、w₃为工程拟合参数，白盒性止于分量定义，合成层显性承认参数性
4. **体系检测并记录Owner背叛，不阻止Owner背叛**：阻止手段在法律/组织层，超出审计体系能力
5. **不保证R_spec v0本身的工程正确性**：审计体系是规格的守门人，不是规格的立法者。锚的最初正确性属于设计质量，超出审计体系能力范围
