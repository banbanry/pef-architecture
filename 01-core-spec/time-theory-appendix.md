# PEF 时间理论附录 — 双轴时间定义

PEF 架构 · 时间理论附录

双轴时间定义 · 反方攻防推演

附属于《PEF V2.3 完整本体重构版》

定位：工程控制平面（物理/哲学/量子层不接战）

引言：为什么单列一份时间附录

PEF 第零公理以“因果顺序（离散时序闭包）”锁死倒果为因。但“时间”一词在工程中极易被误读为物理时空本体（相对论/量子/热力学箭头），从而把一场本应在控制平面解决的争论，拖进宇宙学战场。本附录把 PEF 的“时间”一次性钉死：它是工程控制平面的双轴定义，不是物理时空本体论。凡试图将本系统时间轴映射为物理时空本体的尝试，均属范畴错误，不予接战。

附录给出三件事：（1）双轴时间定义（调度轴 / 判定轴）及其正交性；（2）反方（仅工程控制层）的三轮攻防与逐条挡回；（3）三条工程补丁（迟滞死区 / 预演·事实切割 / 现场时钟源），并配三张图。

## 一、双轴时间定义（核心公理补充）

### 1.1 两条轴，正交而不混用

PEF 同时使用两套“时间/步进”定义。二者正交：调度刻度不定义因果，因果边不依赖刻度来源。混淆两套轴，是把“钟表走了多久”当成“因果是否发生”，也是既往争议的根源。

表1  调度轴与判定轴的正交分工

### 1.2 单向性公理（不可逆性）

在物理世界（工程控制平面），变量一旦由判定轴提交至状态层 M，即成为全局观测事实。除“全空间态停机并重置”这一逻辑悖论（工程上不可实现）之外，不存在逆向回写。所谓“引用未来”，仅指逻辑上禁止跨越判定轴去读取尚未提交的下游状态 S_{t+1}，而非否定时空连续性。

玄幻设定（停时间、杀祖父悖论）在物理世界无人能证明，亦不在本架构讨论范围。PEF 锁的是“发令之后，世界状态不能赖账”——电工、焊工、引信设计师均认此理。

### 1.3 范围切割声明

本架构锁定于工程控制平面。不考虑相对论时间膨胀、量子退相干可逆性、块状宇宙、热力学时间箭头等宇宙学/量子本体议题。这些议题与 PEF 不在同一层，构成范畴错误，不予接战（见图2）。

## 三、工程补丁（直接写入第零公理 / 0.2 节）

下列三条为“时间理论”在落地时的强制约束。建议作为 0.2 节末尾的“工程执行约束”逐字并入主文档；其存在不影响第零公理本体，只补齐工程可实现性。

- 补丁一（现场时钟源）：调度轴 n_t 由部署环境现场时钟源（晶振 / GPS-PPS / PLC 扫描周期 / RTC）提供，PEF 仅要求该轴单调递增、离散可查。π 尾数或 step mod 3 仅作确定性 seed，可无缝替换，架构不依赖任何特殊常数。
- 补丁二（迟滞死区）：判定轴仅响应跨越死区的势能差。在两次提交之间，状态层对同方向微小波动置之不理，仅对反向穿越死区开放新跳转。以此禁止噪声驱动高频因果边（chattering），保证因果边有界。
- 补丁三（预演 / 事实切割）：已提交状态（M 层）不可改写，构成全局观测事实；未提交预演空间（仿真 / 参数配置 / Docker 类回滚）可快照与回退，其输出在进入 M 层前不构成全局事实。即：Docker 回滚的是“没上膛的子弹”，不是“收回已射出的子弹”。
### 3.1 与第零公理的交叉引用（建议并入 3.1 节）

第零公理“变量仅前馈”“结果作下轮输入”中的“周期 / 当前 / 下一周期”，一律指本附录 1.1 节定义的判定轴（势能差事件），非调度轴（太阳历 n_t）。λ(Π_t) 由调度轴驱动，与判定轴正交；Π_t 仅作触发器，不参与因果判定。以此把“时间是什么”的追问永久锁死在工程控制平面。

### 3.2 鲁棒性剖面（三层退化，含时间理论）

时间理论下的系统退化路径与主文档图3一致：正常工况由 LLM+FAISS+Tool 推进判定轴；Tool 超时 / 索引空洞时进入降级（λ×0.8、ρ 缓存收紧、迟滞死区仍生效）；仍不稳则切机械兜底（纯硬件比较器硬断）。已提交事实不可改，是兜底层的最后一道锁。

图3  时间理论下的鲁棒性剖面（三层退化；已提交事实不可改）

## 四、终裁

在工程控制平面（物理世界）内，PEF 时间理论扛得住打：

- · 双轴正交（调度轴 ≠ 判定轴）已明确定义，范畴错误层已开除不接战；
- · 单向性公理（“发令之后不能赖账”）是电工/引信级常识，物理世界无人证伪；
- · 工程层三枪（π 时钟源 / sensor chattering / 软件回滚）均已给出对应补丁（现场时钟源 / 迟滞死区 / 预演·事实切割），无一击穿本体。
本附录与主文档第零公理、0.2 节、3.1 节、第十五章自洽：π 正态性即便未来被证伪，仅影响“用 π 还是 step mod 3”的工程选择，不影响 PEF 时间理论本体。PEF 时间理论封板。
